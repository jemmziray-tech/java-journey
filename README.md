## Overview

`java-journey` is my personal Java learning repository, documenting my progress from programming fundamentals toward writing reliable, maintainable, and well-structured software.

Rather than collecting theory alone, I use this repository to practise concepts, solve programming problems, debug mistakes, and build projects that demonstrate my understanding.

The long-term goal is to develop strong programming fundamentals that support my interests in **artificial intelligence, machine learning, algorithms, and software engineering**.

## Learning Objectives

- Develop a solid understanding of Java syntax and programming fundamentals.

- Learn object-oriented programming and software design principles.

## How I Practise

My learning process follows a simple cycle:

1. **Understand** — learn the concept and its purpose.
2. **Implement** — write a small program using the concept.
3. **Test** — run different inputs and examine the output.
4. **Debug** — identify mistakes and understand why they occurred.
5. **Refine** — improve readability, structure, and correctness.
6. **Document** — commit meaningful progress and record new milestones.

## Running the Exercises

You will need a Java Development Kit (JDK) and a terminal.

For example, to run `WhilePractice.java` from the project root:

```powershell
cd "05-Loops"
javac WhilePractice.java
java WhilePractice
```

Compile and run other exercises using their respective source file and public class names.
